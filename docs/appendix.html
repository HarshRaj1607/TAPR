01

Why inference, not training

An earlier version of this work trained a policy with GRPO using a transition reward. That design has an attribution problem: when the run underperforms, the cause could be the signal, the mixing weight, the KL penalty, the learning rate, or the seed. Nothing can be isolated.

Checkpoint 1 removes all of it. No policy is trained. A fixed set of traces is scored by different scorers and the scores are compared. The only thing that varies between conditions is the prompt given to the judge. Everything else — the traces, the judge model, the decoding settings — is held identical.

The cost of this choice is that Checkpoint 1 cannot say anything about downstream accuracy. It is a measurement of the signal, not of what the signal does to a policy.

02

The five scorers

Same judge model throughout. Only the prompt differs.

ScorerWhat it seesCriteriaScaleNA
isolatedquestion + ONE stepyes, banded0–10no
transitionquestion + all prior steps + this stepyes, banded0–10yes
barequestion + all prior steps + this stepnone0–10no
transition_freequestion + all prior steps + this stepyes, unbanded0–1no
bare_freequestion + all prior steps + this stepnone0–1no

bare is the control, and it is the most interesting design decision on the page. If a scorer given no criteria discriminates as well as one given three explicit conditions, then the explicit conditions add nothing over the model's own notion of entailment. That converts a philosophical question — where does the judgment actually live — into a measurement.

Prefix-only is structural, not instructed

A judge scoring step i is shown steps[:i]. The later steps are not passed to the model at all. This matters because a prompt that merely asks a model to ignore what it can see is not a control — the information is still in context. Here it is absent by construction.

03

The prompts, in full

These are the instruments. The differences between them are the entire experiment, so they are reproduced verbatim rather than summarised.

isolated

You are checking one statement from a reasoning trace.

Problem: {question}

Statement:
{step}

Judge ONLY this statement, on its own. You have no access to any other step,
so do not guess what came before.

First do the check, then score.

CHECK: State the arithmetic or mathematical claim this statement makes, and
verify it. Is the arithmetic correct? Is the claim well-defined?

Then score 0-10:
  0-3   the arithmetic is wrong
  4-6   no clear mathematical claim, or too vague to verify
  7-8   correct but imprecisely stated
  9-10  arithmetic correct and the claim is well-defined

Respond in exactly this format:
CHECK: <your check>
SCORE: <integer 0-10>

transition

You are checking whether one reasoning move is valid.

Problem: {question}

Reasoning so far:
{prior}

Next move:
{step}

FIRST decide whether this is a transition at all.
A transition performs an inference: it concludes, substitutes, simplifies, or
derives something from what came before. A move that merely restates a fact
from the problem, or introduces a piece of common knowledge without inferring
anything, is NOT a transition. If it is not a transition, write SCORE: NA.

If it IS a transition, work through all three checks BEFORE scoring.
Be skeptical. Do not assume a number is legitimate because it sounds plausible.

CHECK 1 - PREMISES. List every number the move uses. Put each into one bucket:
  GIVEN        - stated in the problem, or derived in an earlier step
  WORLD        - a genuine fact not in the problem (e.g. a dozen is 12),
                 and nothing in the problem says otherwise
  CONTRADICTS  - the problem already specified this quantity, and the move
                 uses a different value for it
  FABRICATED   - appears from nowhere and is not a genuine world fact

CHECK 2 - OPERATION. State the operation performed. Is it legitimate here,
and is the arithmetic correct?

CHECK 3 - DIRECTION. Does this move get closer to what the problem asks, or
does it answer a different question or return to an earlier state?

Then score 0-10:
  0-3   any premise is CONTRADICTS or FABRICATED, or the arithmetic is wrong
  4-6   premises and arithmetic fine, but the move does not advance the problem
  7-8   valid and advancing, with minor issues
  9-10  all three checks pass cleanly

A correct operation on a CONTRADICTS or FABRICATED premise still scores 0-3.
WORLD premises are acceptable and cost nothing.

If you are unsure whether a premise contradicts the problem, or unsure whether
the move is valid, score it LOW. Do not resolve doubt in favour of the move.

Judge only on the reasoning shown above. Do not assume later steps.

Respond in exactly this format:
CHECK 1: <each number and its bucket>
CHECK 2: <operation>
CHECK 3: <direction>
SCORE: <integer 0-10, or NA if not a transition>

bare

You are checking whether one reasoning move is valid.

Problem: {question}

Reasoning so far:
{prior}

Next move:
{step}

Does this move follow from what came before? Think it through before scoring.

Respond in exactly this format:
REASONING: <your reasoning>
SCORE: <integer 0-10>

transition_free

You are judging one reasoning move.

Problem: {question}

Reasoning so far:
{prior}

Next move:
{step}

Judge the quality of this move on these metrics:
- the values it uses are stated in the problem or derived in the reasoning so far,
  and none contradict what the problem says
- the operation is legitimate and the arithmetic is correct
- the move advances toward what the problem asks

Score the quality of this move between 0 and 1.

Respond in exactly this format:
REASONING: <your reasoning>
SCORE: <number between 0 and 1>

bare_free

You are judging one reasoning move.

Problem: {question}

Reasoning so far:
{prior}

Next move:
{step}

Does this move follow from what came before?

Score the quality of this move between 0 and 1.

Respond in exactly this format:
REASONING: <your reasoning>
SCORE: <number between 0 and 1>

One design detail worth flagging. The reasoning is requested before the score in every prompt. An earlier version put SCORE: first because it was easier to parse. That produced a judge which emitted a number and then wrote a justification for it — rationalisation, not reasoning. The ordering was reversed and the run was redone. This was an error in the harness design, and it cost a full scoring run.

Steps per trace: min 1, median 4, max 8. 586 steps total.

What a format failure is

The reasoning reaches the correct value and the final-answer marker is mistyped. In one case the trace computed 70,000 and wrote #### 7.0. Graded by final answer, that is a wrong answer. Graded by reasoning, it is sound.

shown 36% of all wrong-answer traces here are format failures, not reasoning failures. Any paper that labels reasoning quality by final-answer correctness on this setup mislabels roughly a third of its failures. This is a finding in its own right, and it was found by reading traces rather than aggregates.

What "sound" actually means here

The 96 traces in the sound group are the ones that reached the correct final answer. They were not verified as having sound reasoning. Some fraction of them will have reached the right number by a wrong route, which is the exact failure mode the project is about. So the sound group is better described as not-known-broken. This is the largest unaddressed weakness in the experiment, and it biases against finding an effect: contamination in the sound group makes every scorer look worse than it is.

05

Judge scale: 7B is unusable, 14B works

Both judges 4-bit quantized (nf4, double quant), do_sample=False, so scores are deterministic.

Qwen2.5-7B-Instruct scored 10 on 99% of steps. On a trace where the generator invented "7 days in a week" when the problem said 3 times a week, the 7B judge described the value as commonly known and gave it 7/10 — and assigned a FABRICATED bucket to a number that did not appear in the step at all.

Qwen2.5-14B-Instruct scored the same step 0/10, correctly identifying the contradiction with the problem statement.

shown LLM-as-judge for transition validity is unreliable at 7B scale. This is worth reporting independently of anything else here: a 7B judge on this task does not merely score generously, it fabricates its own justifications.

A note on what this does and does not establish. It is one model family, two sizes, and the diagnosis came from reading judge output on a handful of traces rather than from a systematic sweep. The direction is clear; the threshold is not.

Results, recomputed

Separation

Separation is the probability that a randomly chosen sound trace scores above a randomly chosen broken trace. 50% is chance. Each trace is summarised by its lowest step score, on the view that one broken link breaks a chain. n = 96 sound, 27 broken. Bootstrap 95% intervals.

Every interval clears 50%, so all three judges do detect broken reasoning. Every interval also contains every other scorer's point estimate. At n = 27 broken traces the scorers cannot be ranked. Transition's higher point estimate is not evidence that transition is better, and the main page is correct not to claim otherwise.

Within-outcome variance

Groups are traces of the same problem that reached the same final answer, with at least two members. This is the metric that matters most for the eventual training application: under GRPO, a group with zero reward variance produces zero advantage and contributes no gradient. A problem whose traces all score identically teaches the policy nothing.

It produced less: 9/33 zero-variance groups against 5/34, and a lower mean SD. On this evidence the transition signal does not supply the within-group gradient TAPR would need.

Banded transition put 448 of 519 scores on exactly 9, and zero on 10. That is not a scale in use; it is a default.

Modal fraction and SD disagree, and the disagreement is not cosmetic. By modal fraction, isolated spreads widest — 34% against 79–86% for the others. By SD, bare is widest at 2.20, just above isolated's 2.14. Bare's SD is inflated by a long low tail sitting underneath a 79% pile-up at the top.

Any claim about which scorer "spreads more" has to name its metric. For TAPR's purposes modal fraction is the more relevant one, because the problem being diagnosed is a ceiling, not overall variance.

The 0–1 scale changed nothing

The unbanded judges genuinely emitted 0–1 values — SCORE: 0.7, SCORE: 0.5 — and the harness rescales by 10 on write so everything sits on a common axis. But they used one decimal place only. The observed values were 0, 0.2, 0.3, 0.5, 0.6, 0.7, 0.8, 0.9 and 1.0.

That is eleven available slots. A 0–10 integer scale is also eleven slots. Effective resolution is identical. Two things follow:

  • Comparing isolated on 0–10 against the free scorers on 0–1 is not confounded by granularity. That comparison stands.
  • Whatever moved transition from 86% to 64% was not the change of scale.

07

Confounds

The bands hypothesis is confounded five ways

The main page reports that removing the bands lowered the pile-up from 86% to 64%. That number is correct. The attribution is not yet established, because the banded and unbanded transition prompts differ in five respects, not one:

  1. Bands removed
  2. Scale changed from 0–10 to 0–1
  3. The NA option removed — the free prompt has no "not a transition" escape
  4. The three explicit CHECK 1/2/3 steps collapsed into a bullet list
  5. The skepticism instruction deleted — "if unsure, score LOW. Do not resolve doubt in favour of the move"

The third is the most damaging. Banded transition returned NA on 64 of 586 calls, and on 24% of all step-0 calls — concentrated on setup lines that restate the problem without inferring anything. transition_free has no NA, so those steps are now scored, and setup lines score high. That alone could account for the modal value moving to 10.

predicted The bands hypothesis is untested — not confirmed, and not refuted. Testing it needs a prompt that changes only the bands, keeping the 0–10 scale, the NA option, the CHECK structure and the skepticism line.

The bare to bare_free pair is the clean comparison, because only the scale changed there. It moved 79.3% to 76.5%, and SD fell from 2.20 to 1.95. On the only uncontaminated comparison available, the scale change did nothing and may have tightened the distribution slightly. Caveat: 581 scores against 119, on different traces.

Different step populations

transition's distribution is computed over 519 steps and isolated's over 586. They are not the same population of steps.

The direction of this favours the argument rather than undermining it: the 64 excluded steps are setup lines, which are exactly the steps that would have scored high. Removing them should lower transition's pile-up, and it is still 86%. But a reader who sees n=519 next to n=586 is entitled to know why, so it is stated here.

Two scales, two different trace sets

The banded scorers ran on 138 traces; the unbanded scorers ran on 30. No banded-versus-unbanded number on the main page compares the same problems.

08

What the results support

The hypothesis failed

Predicted: the transition judge catches broken reasoning much better than the isolated judge, and produces more within-outcome variance. Shown: separation is statistically indistinguishable across all three scorers, and within-outcome variance is worse for transition than for isolated.

What survives, stated precisely

ClaimStatus
All three judges detect broken reasoning above chanceshown
The three scorers cannot be ranked at this sample sizeshown
Explicit criteria add nothing over asking "does this follow?"shown
LLM-as-judge is unreliable at 7B for this taskshown
Final-answer correctness mislabels ~36% of failures hereshown
The transition signal does not yet give a within-group gradientshown
Bands caused the score collapsepredicted
Broken transitions are rare on GSM8K, so the ceiling is a task propertypredicted
Context-aware scoring beats context-free scoringpredicted

The criteria result is worth reading positively

bare ties transition on separation. The obvious reading is that TAPR's three conditions failed to earn their place. There is a second reading which is stronger and which Harsh arrived at independently: if the judgment is baked into criteria the researcher wrote, then human judgment has been relocated rather than removed — the same critique he had made of policy-document approaches elsewhere. On that reading, a criteria-free scorer matching a criteria-laden one is the result, not a failure, and the surviving claim is the simpler one.

The rarity reframe

predicted isolated has by far the smallest pile-up at 34%, and it is banded. So bands cannot be the main driver. What separates it from the other four is that it never sees the prior chain.

The proposed mechanism: given the full prior chain, most individual moves genuinely do follow. Local coherence is the norm even in traces that end up wrong — which is the premise of the whole project. So "does this follow?" is usually yes, and the judge says 10. isolated is asked a harder, narrower question — is this statement well-formed on its own — which more steps fail.

If that is right, the ceiling is a property of the task rather than a defect in the prompt: transition validity is a rare-failure signal, and the information lives in the tail rather than the average. It would also explain the within-outcome result directly — if roughly three quarters of steps score at the top, traces sharing an outcome get identical minimums.

This is a hypothesis with a plausible mechanism and no decisive test behind it yet. It should be read as the most interesting thing the experiment produced, and as the thing most likely to be wrong.

09

Limitations

  1. n = 27 broken traces. Too few to rank scorers. This is the binding constraint on every comparative claim in the work.
  2. "Sound" means "not known broken." The 96 correct-answer traces were never verified as having sound reasoning.
  3. The bands hypothesis is confounded five ways and untested.
  4. Banded and unbanded scorers ran on different trace sets, 138 against 30.
  5. Different step populations across scorers, 519 against 586, from NA exclusion.
  6. One dataset, one generator, one judge family. GSM8K, a 3B generator, a Qwen judge. Nothing here transfers without testing.
  7. Single judge run. Sampling is off so scores are deterministic, but deterministic is not robust. No prompt-perturbation check was run.
  8. The confound argument is half-discharged. Checkpoint 1 validates the signal alone. The mixing half of the argument needs a mixing comparison against a signal already known to be sound, which does not exist yet.
